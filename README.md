# Ayesha Nusrat — Data Science & AI Portfolio

A responsive portfolio website inspired by the supplied editorial UI/UX portfolio reference.

## Theme
- Near-black background
- Deep burgundy / wine accents
- Warm cream typography
- Muted taupe secondary text
- Editorial serif + technical monospace pairing
- Thin borders, circular data motifs and analytical visual language

## Files
- `index.html` — portfolio content
- `styles.css` — responsive visual system
- `script.js` — subtle reveal animations and current year
- `ayesha-profile.png` — portfolio profile illustration integrated into the hero and About section

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

Before publishing, replace the LinkedIn placeholder URL with your actual profile URL and update any project links you want to feature.
